# Galleria Slideshow Site

A responsive art gallery slideshow website.  
Users can browse a collection of artworks, view details about each painting, and navigate through the gallery as a slideshow.

## Overview

This project was built as a Frontend Mentor challenge.  
The main goal was to practice creating a responsive layout, working with components, displaying gallery data, and building slideshow navigation.

## Features

- View a gallery of artworks
- Open artwork details
- Navigate between slides
- View artwork images, titles, artists, and descriptions
- Responsive design for mobile, tablet, and desktop screens
- Clean and modern user interface

## Technologies Used
- HTML
- JavaScript
- CSS
- Tailwind
- Vite
